# ASME 标注法（美国机械工程师协会）

> 依据：ASME Y14.5-2018《Dimensioning and Tolerancing》、
> ASME Y14.1《Drawing Sheet Size and Format》、ASME Y14.2《Line Conventions and Lettering》
>
> **每次标注前必须通读本文件。**

---

## 0. 与 GB / ISO 的主要差异（换标准时先看这张表）

| 项目 | GB | ISO | **ASME** |
|---|---|---|---|
| 直径符号 | φ | ⌀ | **⌀**（U+2300） |
| 单位 | mm 不注 | mm 不注 | **必须注明体系**（INCH 或 mm），标题栏声明 |
| 投影法 | **第一角** | 第一角 | **第三角**（Third Angle） |
| 一般公差 | GB/T 1804 | ISO 2768 | **标题栏 General Tolerance 声明** |
| 理论正确尺寸 | 罕见 | 罕见 | **方框内标出**（Basic Dimension） |
| 基准体系 | 简单基准 | 简单基准 | **基准参考框架 DRF**（A/B/C） |
| 几何公差 | GB/T 1182 | ISO 1101 | **ASME Y14.5**（自成体系，规则更严） |
| 表面粗糙度 | GB/T 131 | ISO 1302 | **ASME B46.1**（Ra µin 或 µm） |
| 角度 | 度/分/秒 | 度/分/秒 | 度（可用度分秒） |

⚠ **投影法不同是最大陷阱**：ASME 默认**第三角投影**。GB/ISO 用第一角。
第三角：俯视图放在主视图**上方**，左视图放在主视图**左侧**（与第一角相反）。

## 1. 硬性规则

| 编号 | 规则 |
|---|---|
| ASME-A | 每个尺寸**只标注一次**（No duplicate dimensions） |
| ASME-B | **不得出现封闭尺寸链** |
| ASME-C | 尺寸线**不得与其他图线重合** |
| ASME-D | **尺寸数字不得被图线穿过** |
| ASME-E | 尺寸标注**不得侵入其他视图的图形范围** |
| ASME-F | 尺寸应布置在**离被注特征最近的一侧** |
| ASME-G | 装配图/加工图尺寸必须**完整可制造**（fully defined） |

## 2. 单位体系（强制）

ASME 图样**必须明确声明**单位：

- `DIMENSIONS ARE IN INCHES` — 英寸制
- `DIMENSIONS ARE IN MILLIMETERS` — 公制

- 英寸制：默认保留 **2 位小数**（如 `0.50`），无前导零（`.50`）可选。
- 公制：保留 1~2 位小数（如 `5.6`）。
- **不允许英寸与毫米混标**（除非括号内为参考尺寸）。

## 3. 尺寸要素

- **尺寸界线**：细实线，从特征引出，与特征垂直。
- **尺寸线**：细实线，不得与其他图线重合。
- **终端**：**箭头**（ASME 明确要求箭头，不用斜线）。
- **尺寸数字**：字高按 ASME Y14.2；写在尺寸线上方，字头朝上（水平尺寸）或朝左（垂直尺寸）。

## 4. 直径 / 半径 / 球面

```
直径：⌀      例：⌀.250 或 ⌀6.35     尺寸线通过圆心，双箭头
半径：R      例：R.125               尺寸线自圆心引出，单箭头
球面：S⌀（球直径）/ SR（球半径）
```

## 5. 理论正确尺寸（Basic Dimension）★ ASME 特色

用于位置公差（位置度、轮廓度）的**理论正确尺寸**，必须写在**方框**内：

```
┌──────┐
│ 32.0 │     位置度公差 φ0.2 以此为基准
└──────┘
```

- 方框内尺寸**不带公差**（公差由形位公差框格给出）。
- GB/ISO 中也可用（加方框），但 ASME 用得最普遍。

## 6. 基准与基准参考框架（DRF）

- 基准用**方框字母**表示：`[A]` `[B]` `[C]`
- 三个基准构成**基准参考框架**，优先顺序：主基准 A → 次基准 B → 第三基准 C
- 基准要素标在**实际表面**或**尺寸线**上

## 7. 对称结构

- 对称件以**对称中心面/中心线**为基准标注
- 对称要素优先标**对称跨距**（跨中心线）
- 对称件可标一半，对称性由中心线表达
- 不得因对称标注形成封闭尺寸链

## 8. 重复要素

| 场景 | ASME 写法 |
|---|---|
| n 个相同孔 | `2X ⌀.250` 或 `2X ⌀6.35` |
| 盲孔 | `⌀.250 ↧ .25 DEEP` |
| 通孔 | `⌀.250 THRU` |
| 计数前缀 | **`2X`（大写 X）** |

## 9. 一般公差（标题栏声明）

ASME 没有统一的一般公差标准号，必须在标题栏或注释中写明：

```
UNLESS OTHERWISE SPECIFIED:
  DIMENSIONS ARE IN MILLIMETERS
  TOLERANCES:
    X.X   ±0.5
    X.XX  ±0.25
    X.XXX ±0.125
  ANGLES  ±0.5°
  SURFACE FINISH  Ra 3.2 µm
```

## 10. 表面粗糙度（ASME B46.1）

- 单位：**µin**（微英寸）或 **µm**（微米），须与尺寸单位体系一致。
- 符号与 ISO 1302 基本一致。

## 11. 标注完成后自查清单

```
[ ] 1. 单位体系已声明（INCH 或 mm）
[ ] 2. 投影法为第三角（如适用）
[ ] 3. 数值真实性：几何值 × 比例换算正确
[ ] 4. 特征覆盖：圆/弧都有 ⌀ 或 R；孔有直径+深度
[ ] 5. 无重复尺寸
[ ] 6. 无封闭尺寸链
[ ] 7. 对称件：中心线已画，要素用跨距标
[ ] 8. 方位就近
[ ] 9. 不侵入其他视图
[ ] 10. 数字不被压线
[ ] 11. 平行尺寸线间距 ≥ 7mm
[ ] 12. 理论正确尺寸已加方框（若用位置度）
[ ] 13. 标题栏公差声明完整
```
