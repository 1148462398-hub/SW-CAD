# GB 标注法（中国国家标准）

> 依据：GB/T 4458.4-2003《机械制图 尺寸注法》、GB/T 16675.2《简化表示法 尺寸注法》、
> GB/T 4458.1《视图》、GB/T 14691《字体》、GB/T 1804《一般公差》
>
> **每次标注前必须通读本文件，逐条自查。**

---

## 0. 硬性禁令（违反即为不合格图）

| 编号 | 禁令 | 自查方式 |
|---|---|---|
| GB-A | **不得出现封闭尺寸链** | 检查同一方向尺寸链：链上各段之和 == 总长 即为封闭，必须去掉一段 |
| GB-B | **同一尺寸只标一次**，且标在反映该结构最清晰的视图上 | 统计所有尺寸值，重复值必须能解释为不同方向/不同特征 |
| GB-C | **尺寸线不得与其他图线重合**，也不得画在其延长线上 | 尺寸线碰到轮廓线/中心线即为违规 |
| GB-D | **尺寸数字不得被任何图线穿过** | 文字包围盒内不应有图线 |
| GB-E | **尺寸标注不得侵入其他视图的包围框** | 尺寸包围盒 vs 其它视图几何范围求交，必须为空 |
| GB-F | **尺寸应布置在离被注特征最近的一侧** | 特征在视图上半部就标上方，不能甩到对面 |
| GB-G | **文字不得进入 30° 阴影区**（斜向尺寸的拥挤区） | 斜向尺寸文字与图线夹角检查 |

## 1. 单位

- 图样中以 **mm 为单位时，不标注单位代号或名称**。尺寸数字后面不写 `mm`。
- 若采用其他单位（英寸、度、分、秒等），**必须注明**。
- 毫米单位已在标题栏「比例」同区或技术要求中默认，无需在每个尺寸后重复。

## 2. 基本规则

1. 机件的**真实大小**以图样所注尺寸数值为依据，与图形大小及绘图准确度无关。
2. 图样中的尺寸以毫米为单位时，不需标注计量单位。
3. 图样中所注尺寸为该图样所示机件的**最后完工尺寸**，否则应另加说明。
4. 机件的**每一尺寸一般只标注一次**，并应标注在反映该结构最清晰的图形上。

## 3. 尺寸要素的画法

| 要素 | 规定 |
|---|---|
| **尺寸界线** | 用细实线绘制；应由图形的轮廓线、轴线或对称中心线引出，也可直接利用轮廓线、轴线或对称中心线作尺寸界线；一般应与尺寸线垂直，必要时才允许倾斜 |
| **尺寸线** | 用**细实线**绘制；不得与其他图线重合或画在其延长线上；标注线性尺寸时，尺寸线必须与所标注的线段平行 |
| **尺寸终端** | 一般为箭头；箭头尖端与尺寸界线接触，不得超出或离开 |
| **尺寸数字** | 字高按图幅（A3 取 3.5mm）；一律写在尺寸线的上方（水平尺寸）或左侧（垂直尺寸）；**不得被任何图线穿过**，不可避免时应断开图线 |

## 4. 直径、半径、球面

```
直径：φ     例：φ5.6     尺寸线通过圆心，两端箭头指向圆周
半径：R     例：R10      尺寸线自圆心引出，一端箭头指向圆弧
球面：Sφ / SR            球直径用 Sφ，球半径用 SR
```

- **直径尺寸的尺寸线应通过圆心**，两端箭头指向圆周。
- 圆较小时（箭头放不下），可**引出标注**：尺寸线通过圆心、箭头指向圆周，再用引线把数字引到外面。
- 半径尺寸的尺寸线应**自圆心引出**，只画一个箭头。
- 符号用 AutoCAD 的 `%%C` 生成（存 `%%C` 而不是直接打字符，换字体不会变问号）。

## 5. 对称结构（重点）

**规则 5.1**：对称结构的尺寸**宜以对称中心线为基准**标注，而不是从某一边缘量起。

**规则 5.2**：对称结构可只标一半，对称性由**中心线（细点画线 CENTER）**表达。

**规则 5.3**：对称分布的孔、槽、凸台等**重复对称要素**，优先标注**对称跨距**（尺寸线跨过中心线、连接对称两要素），而不是标"某一边缘到特征的距离"。

典型对比（零件宽 54，对称轴 X=27，两孔在 X=11 和 X=43）：

```
✗ 错误（封闭尺寸链 + 不表达对称意图）
    ├─11─┼────── ? ──────┼─11─┤   + 54
    ├──────── 43 ────────┤       + 54   ← 11/43/54 三者封闭

✓ 正确（GB 对称标注）
    ├──────── 54 ────────┤       总宽
         ├─── 32 ───┤            孔距（跨中心线）
              ┊                   中心线（CENTER 点画线）
```

## 6. 重复要素简化注法（GB/T 16675.2）

| 场景 | 写法 |
|---|---|
| n 个相同直径的孔 | `2×φ5.6` 或 `2-φ5.6` |
| 盲孔 | `φ5.6 深6`（深度紧跟直径） |
| 通孔 | `φ5.6 通` |
| n 个相同的槽 | `3× 宽×深` |

## 7. 尺寸布置

1. 尺寸应布置在**图形轮廓线以外**，尽量靠近被注轮廓。
2. **平行尺寸线之间的间距不小于字高**（3.5mm），实际取 **7~10mm**，同一方向的尺寸应**整齐分层排列**。
3. 同一视图内的尺寸应尽量集中在一侧，避免左右分散。
4. 特征偏上 → 尺寸标上方；偏下 → 标下方；偏左 → 标左侧；以此类推（就近原则）。
5. 尺寸不得与其他视图的图形重叠（多视图共板时尤其注意）。

## 8. 标题栏与图框（GB/T 10609.1 / GB/T 14689）

- 图幅：A0 841×1189、A1 594×841、A2 420×594、A3 297×420、A4 210×297（mm）。
- 装订边一般留 25mm，其余边 5~10mm。
- 标题栏必须填：**图样名称、图样代号、比例、重量、材质、设计/审核/批准签名与日期、张次**。
- **比例必须在标题栏注明**（如 2:1、1:2），且应与实际绘图比例一致。
- 未注公差按 **GB/T 1804-m**（中等），应在技术要求中写明。

## 9. 技术要求（左下角或标题栏上方）

常用条目模板：

```
技术要求
1. 未注尺寸公差按 GB/T 1804-m。
2. 未注圆角 R1。
3. 未注倒角 C0.5。
4. 表面粗糙度除标注外 Ra3.2。
5. 未注单位为 mm。
```

## 10. 表面粗糙度（GB/T 131）

- 符号：基本符号（√）、去除材料（带横线）、不去除材料（带小圆）。
- 标注在可见轮廓线、尺寸界线或它们的延长线上，尖端指向表面。
- 同一表面只注一次；多数表面相同时可统一注在图样右上角并加 "其余"。

## 11. 常用公差与配合

| 类型 | 国标 | 说明 |
|---|---|---|
| 尺寸公差 | GB/T 1800.1 | H7/h6 等配合代号 |
| 未注公差 | GB/T 1804 | f 精密 / m 中等 / c 粗糙 / v 最粗 |
| 几何公差 | GB/T 1182 | 直线度、平面度、同轴度… |
| 形位公差框格 | 三格：符号 / 公差值 / 基准 | 基准用大写字母 |

## 12. 标注完成后的强制自查清单

按顺序逐条过，全部通过才算完成：

```
[ ] 1. 数值真实性：几何值 × 比例换算是否正确（比例 2:1 则真实 = 几何/2）
[ ] 2. 特征覆盖：所有圆/弧都有 φ 或 R；所有孔都有直径+深度（盲孔标深、通孔标通）
[ ] 3. 无重复：同一特征只标一次，跨视图不重复
[ ] 4. 无封闭链：同一方向尺寸链不得闭合
[ ] 5. 对称件：对称轴线已画，对称要素用跨距标注
[ ] 6. 方位就近：每个尺寸都在离其被注特征最近的一侧
[ ] 7. 不侵入其他视图框：尺寸包围盒与其他视图几何范围无交集
[ ] 8. 无压线：尺寸数字不被图线穿过
[ ] 9. 分层整齐：平行尺寸线间距 ≥ 7mm
[ ] 10. 单位：mm 不写单位
[ ] 11. 标题栏：比例、材质、名称、代号已填
[ ] 12. 技术要求：未注公差、未注圆角、未注单位已写
```
