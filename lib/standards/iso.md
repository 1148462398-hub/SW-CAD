# ISO 标注法（国际标准化组织）

> 依据：ISO 129-1:2018《Technical product documentation — Indication of dimensions and tolerances》、
> ISO 129-2、ISO 3098-2《字体》、ISO 2768《一般公差》
>
> **每次标注前必须通读本文件。**

---

## 0. 与 GB 的主要差异（换标准时先看这张表）

| 项目 | GB（中国） | ISO（国际） |
|---|---|---|
| 直径符号 | **φ**（希腊字母） | **⌀**（U+2300，圆圈加斜杠） |
| 单位 | mm 不注 | mm 不注（同） |
| 一般公差 | GB/T 1804 | **ISO 2768**（f/m/c/v 同级） |
| 字体 | GB/T 14691（长仿宋） | **ISO 3098-2**（无衬线） |
| 表面粗糙度 | GB/T 131 | **ISO 1302** |
| 几何公差 | GB/T 1182 | **ISO 1101** |
| 基准符号 | 方框字母 | 方框字母（同） |
| 对称标注 | 中心线 + 跨距 | 中心线 + 跨距（同） |
| 封闭尺寸链 | 禁止 | **禁止**（同） |

**切换要点：只需把 `φ` 换成 `⌀`，其余规则基本一致。**

## 1. 硬性规则

| 编号 | 规则 |
|---|---|
| ISO-A | 每个尺寸**只标注一次**，不得重复 |
| ISO-B | **不得出现封闭尺寸链** |
| ISO-C | 尺寸线**不得与其他图线重合**或在其延长线上 |
| ISO-D | **尺寸数字不得被图线穿过** |
| ISO-E | 尺寸应标注在**最能清晰表达该特征**的视图上 |
| ISO-F | 尺寸标注**不得侵入其他视图的图形范围** |
| ISO-G | 尺寸应布置在**离被注特征最近的一侧** |

## 2. 单位

- 默认单位 **mm**，尺寸数字后**不写单位**。
- 若使用英寸或其他单位，**必须明确标注**（如 `1.25 in`）。
- 图样应在标题栏或注释中说明默认单位体系。

## 3. 尺寸要素

- **尺寸界线**：细实线，从轮廓线、轴线或中心线引出；与被注面垂直。
- **尺寸线**：细实线，平行于被注尺寸方向；**不得与其他图线重合**。
- **终端**：箭头（ISO 允许斜线终端，但机械图首选箭头）。
- **尺寸数字**：字高按 ISO 3098-2；一般写在尺寸线上方，**不得被图线穿过**。

## 4. 直径 / 半径 / 球面

```
直径：⌀      例：⌀5.6     尺寸线通过圆心，双箭头指向圆周
半径：R      例：R10      尺寸线自圆心引出，单箭头
球面：S⌀ / SR
```

- 小圆（箭头放不下）用**引线引出**标注，引出线从圆周外引到尺寸数字。
- 直径尺寸的尺寸线**必须通过圆心**。

## 5. 对称结构

- 对称结构应以**对称中心线为基准**标注，而不是从单侧边缘量起。
- 对称要素（孔、槽、凸台）优先标**对称跨距**（尺寸线跨中心线）。
- 对称件可只标一半，对称性由**中心线（细点画线）**表达。
- 不得因标对称件而产生封闭尺寸链。

## 6. 重复要素

| 场景 | ISO 写法 |
|---|---|
| n 个相同孔 | `2×⌀5.6` |
| 盲孔 | `⌀5.6 ↧ 6`（深度符号）或 `⌀5.6 DEEP 6` |
| 通孔 | `⌀5.6 THRU` |

## 7. 尺寸布置

1. 尺寸布置在轮廓线**外侧**，靠近被注特征。
2. 平行尺寸线间距 **≥ 字高**，实际取 7~10mm，分层整齐。
3. 尺寸数字方向：水平尺寸数字水平书写；垂直尺寸数字朝左读。
4. 角度数字一律**水平书写**。
5. 避免尺寸线与图线交叉；不可避免时图线断开。

## 8. 一般公差（ISO 2768）

| 等级 | 线性尺寸范围（mm） | 用途 |
|---|---|---|
| f（fine） | 0.5~3: ±0.05 | 精密 |
| m（medium） | 0.5~3: ±0.1 | **默认** |
| c（coarse） | 0.5~3: ±0.2 | 粗加工 |
| v（very coarse） | 0.5~3: ±0.5 | 最粗 |

技术要求模板：`General tolerances according to ISO 2768-m.`

## 9. 表面粗糙度（ISO 1302）

- 符号分三类：基本符号、去除材料、不去除材料。
- 标注在表面可见轮廓线或其延长线上，尖端指向表面。
- 统一要求可注在图样右上角并加 `all others`。

## 10. 标注完成后自查清单

```
[ ] 1. 数值真实性：几何值 × 比例换算正确
[ ] 2. 特征覆盖：圆/弧都有 ⌀ 或 R；孔有直径+深度
[ ] 3. 无重复
[ ] 4. 无封闭尺寸链
[ ] 5. 对称件：中心线已画，要素用跨距标
[ ] 6. 方位就近
[ ] 7. 不侵入其他视图
[ ] 8. 数字不被压线
[ ] 9. 平行尺寸线间距 ≥ 7mm
[ ] 10. 单位：mm 不写单位
[ ] 11. 标题栏：比例、材质、名称、代号
[ ] 12. 一般公差按 ISO 2768-m 已注明
```
